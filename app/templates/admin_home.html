Embassy admin — overview

Read-only browse over the run corpus. This panel is for operators; it is separate from the game-client Embassy and excluded from the published client OpenAPI contract.

  • Runs — filter/sort every uploaded run; drill into the raw action log + instruments.
  • Identities — handles, consent, run counts (recovery codes are hashed, never shown).
  • Bests — the personal-bests query for any fingerprint, freely sliced.
  • Daily — inspect the deterministic descriptor for any date.
  • Instruments — aggregate the TUNING.md dev-instrument targets across the corpus.
  • Health — advertised versions + config posture.
